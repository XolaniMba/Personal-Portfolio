About

Software Developer & IT Professional

Early-career developer with real enterprise banking experience, growing into modern software engineering.

I'm an early-career software developer with real experience working inside enterprise banking systems — not just in theory, but in production, where uptime and accuracy actually matter.

As a Junior COBOL Developer at Absa Group, I worked on Hogan/ELIPS banking systems: writing and maintaining COBOL, testing changes, debugging issues, and getting to the root cause when something broke in production. It gave me a real appreciation for the discipline enterprise software demands, and for how much legacy technology still quietly runs the world's financial systems.

Outside of that, I build with more modern tools — Java, JavaScript, Python and SQL, backend work on databases like MongoDB and PostgreSQL. I've used that stack on projects like an automated attendance-tracking system and a bank management backend, work that pushed me to build REST APIs, test my own code properly, and think about how software actually gets used.

I'm also spending time growing into cloud (AWS, Azure), data and analytics, and cybersecurity — areas I'm actively building toward rather than claiming to have mastered. What stays constant is how I approach the work: staying curious, taking ownership, learning quickly, and communicating clearly with the people I'm working with.
